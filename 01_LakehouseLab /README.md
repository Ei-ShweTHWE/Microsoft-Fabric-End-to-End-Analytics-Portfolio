# 01 - Lakehouse Lab (Microsoft Fabric)

## 📌 Objective
This lab demonstrates the implementation of a Microsoft Fabric Lakehouse architecture (**SalesLakehouse**) to ingest, store, query, and manage structured analytics data within OneLake.

## 🛠️ Key Components & Workflow
1. **Unified Storage (OneLake):** Leveraged Microsoft Fabric's OneLake storage layer to house raw and curated delta tables seamlessly.
2. **Visual Querying & Data Transformation:** Utilized **Visual queries** within the Lakehouse environment to inspect data, group rows, and analyze order structures.
3. **Data Validation:** Executed queries on sales transactions (e.g., inspecting `SalesOrderNumber` and grouping order lines) to verify data integrity before downstream modeling.
