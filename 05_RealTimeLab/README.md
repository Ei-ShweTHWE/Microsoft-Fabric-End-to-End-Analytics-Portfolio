# 05 - Real-Time Analytics Lab (Microsoft Fabric)

## 📌 Objective
This lab demonstrates real-time data streaming, monitoring, and database management using Microsoft Fabric **Eventhouse** (`StockEvenhouse`). It focuses on handling high-frequency streaming data, tracking ingestion metrics, and managing KQL databases.

## 🛠️ Key Components & Workflow
1. **Eventhouse & KQL Database:** Configured and managed real-time databases optimized for streaming data workloads (`StockEvenhouse`).
2. **Data Activity Tracking:** Monitored ingestion metrics (handling over 2.7M rows) and active query performance in real-time.
3. **Table Management & Policies:** Configured real-time tables (`stock`), **Ingestion Mappings**, and **Update Policies** to process incoming telemetry or financial stock feeds.
4. **Storage Optimization:** Evaluated compressed vs. original data sizes (e.g., 26.4MB compressed from 482.1MB original storage).
