# 06 - Sales Semantic Model & Power BI Lab (Microsoft Fabric)

## 📌 Objective
This lab demonstrates the creation of an enterprise semantic model and dimensional data modeling using Microsoft Fabric **Sales Semantic Model**. It focuses on implementing a optimized Star Schema architecture and configuring relationships for advanced business intelligence reporting.

## 🛠️ Key Components & Workflow
1. **Star Schema Architecture:** Designed optimized **1-to-many relationships** connecting central transactional fact tables (`FactSalesOrder`, `sales`) with clean, optimized dimension tables:
   - `DimDate` (Date and time attributes)
   - `DimProduct` (Product details and categories)
   - `DimCustomer` (Customer demographics and regions)
2. **Semantic Modeling & Calculations:** Utilized modeling tools to configure column properties, relationships, and manage data categories.
3. **DAX Measure Preparation:** Structured foundational metrics and time-intelligence calculations for reporting.
