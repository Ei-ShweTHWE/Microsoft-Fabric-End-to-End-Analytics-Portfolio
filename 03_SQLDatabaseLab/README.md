# 03 - SQL Database Lab (Microsoft Fabric)

## 📌 Objective
This lab demonstrates relational database querying and management using Microsoft Fabric **SQL Database**. It focuses on executing T-SQL scripts to explore schema metadata, query relational tables, and perform data aggregations.

## 🛠️ Key Components & Workflow
1. **Database Exploration & Schemas:** Navigated database objects (`dbo` and `SalesLT` schemas) within the Fabric SQL database environment.
2. **T-SQL Querying:** 
   - Queried `INFORMATION_SCHEMA.TABLES` to retrieve available base tables and schemas.
   - Executed sample queries (`SELECT TOP 10 * FROM SalesLT.Customer;`) to inspect customer records.
   - Performed aggregations (`SELECT COUNT(*) AS TotalCustomers FROM SalesLT.Customer;`) to validate record counts.
3. **Execution & Results:** Successfully ran queries with optimized execution times and validated data integrity.
