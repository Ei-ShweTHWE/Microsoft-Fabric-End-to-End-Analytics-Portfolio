# 02 - Warehouse Lab (Microsoft Fabric)

## 📌 Objective
This lab focuses on enterprise data warehousing using Microsoft Fabric **SalesWarehouse**. It demonstrates relational table management, schema organization, and visual query transformations.

## 🛠️ Key Components & Workflow
1. **Relational Data Management:** Organized database schemas (including system and security schemas) within a managed Fabric Data Warehouse environment.
2. **Visual Querying & Table Joins:** Used **Visual queries** to join dimension tables (`DimProduct`) with transactional fact tables (`FactSalesOrder`).
3. **Analytical Preview:** Examined key sales metrics such as `SalesOrderKey`, `SalesOrderDateKey`, `Quantity`, and `SalesTotal` to validate relational model performance.
